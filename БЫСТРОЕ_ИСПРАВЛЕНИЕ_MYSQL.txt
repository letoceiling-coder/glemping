  БЫСТРОЕ ИСПРАВЛЕНИЕ ПРОБЛЕМЫ С MySQL В OPENSERVER
═══════════════════════════════════════════════════════════════

ПРОБЛЕМА: Папка data в MySQL-8.0-Win10 отсутствует или повреждена

РЕШЕНИЕ 1: Переинициализация MySQL (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════

1. Откройте командную строку ОТ ИМЕНИ АДМИНИСТРАТОРА

2. Перейдите в папку bin MySQL:
   cd C:\OSPanel\modules\database\MySQL-8.0-Win10\bin

3. Инициализируйте базу данных:
   mysqld.exe --initialize-insecure --datadir=C:/OSPanel/modules/database/MySQL-8.0-Win10/data

   ВАЖНО: Это создаст новую базу данных БЕЗ пароля для root!
   
4. После успешной инициализации запустите OpenServer

5. Подключитесь к MySQL через phpMyAdmin или командную строку:
   mysql -u root

═══════════════════════════════════════════════════════════════

РЕШЕНИЕ 2: Переустановка модуля MySQL
═══════════════════════════════════════════════════════════════

1. Откройте OpenServer
2. Нажмите на иконку OpenServer → Настройки → Модули
3. Найдите MySQL-8.0-Win10
4. Удалите модуль
5. Установите модуль заново
6. Запустите OpenServer

═══════════════════════════════════════════════════════════════

РЕШЕНИЕ 3: Использование другой версии MySQL
═══════════════════════════════════════════════════════════════

Если MySQL 8.0 не работает, попробуйте установить:
- MySQL-5.7-Win10
- MariaDB-10.11-Win10

После установки обновите настройки в файле .env проекта:
DB_PORT=3306  (или другой порт, если используется другая версия)

═══════════════════════════════════════════════════════════════

ПРОВЕРКА ПОСЛЕ ИСПРАВЛЕНИЯ
═══════════════════════════════════════════════════════════════

1. Убедитесь, что MySQL запустился (зелёный индикатор в OpenServer)
2. Откройте phpMyAdmin: http://localhost/openserver/phpmyadmin/
3. Проверьте подключение из проекта:
   php artisan migrate:status

═══════════════════════════════════════════════════════════════

ЕСЛИ НИЧЕГО НЕ ПОМОГЛО
═══════════════════════════════════════════════════════════════

1. Проверьте логи MySQL в:
   C:\OSPanel\logs\MySQL\

2. Запустите MySQL вручную для просмотра ошибок:
   cd C:\OSPanel\modules\database\MySQL-8.0-Win10\bin
   mysqld.exe --console

3. Проверьте, не занят ли порт 3306:
   netstat -ano | findstr :3306

4. Остановите службу MySQL Windows (если установлена):
   net stop MySQL80
